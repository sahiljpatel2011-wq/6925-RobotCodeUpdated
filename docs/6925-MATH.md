## 2. Limelight `ty` → camera-to-tag range

```
angleDeg = 26 + ty
range_in = 18.86 / tan(angleDeg)     // inches, ground-plane camera → tag
```

Reject if:

- `angleDeg` wrapped into [0, 180) is within **2° of 0° or 90°**
- `|tan| < 0.02`
- range not finite, **≤ 0**, or **> 400 in**

Inverse (tests / geometry check only):

```
ty = atan(18.86 / cameraToTagInches) − 26°
```

**Worked example, ty = 0**

- tan(26°) ≈ 0.4877
- camera-to-tag ≈ 18.86 / 0.4877 ≈ **38.7 in**
- hub range ≈ 38.7 + 23.5 ≈ **62.2 in** (inside the live table)

The **−1.46 in** camera-behind-center is **not** in this triangle. The shot table was tuned with this camera range, not robot-origin range.

## 3. Hub range for the shot table

```
hubRangeInches = cameraToTagInches + 23.5
```

Live RB path (`RobotCommands.aimAndWindUp`):

```
distance = movingShotInches(cameraToTag + 23.5)
hood + RPM = ShotTable.get(distance)   // clamp 47–110 in
```

This is 1-D along roughly forward (`cam + 23.5`), not `hypot(lateral, forward)`. At ~20° `tx` the error is about **1 in** vs true hypot — small vs the table.

## 4. Hub aim `tx` (drivetrain turn)

Limelight **+tx = target to the right** of the crosshair.

```
cam = cameraToTagInches(ty)
hubLateral = cam * sin(tx) + lateralOffsetInches(tagId)
hubForward = cam * cos(tx) + 23.5
hubTxDeg  = atan2(hubLateral, hubForward)     // degrees, same sign as Limelight tx
```

**Lateral signs (8 in)** — hub center relative to the tag, in camera-right coordinates:

| Tags | Offset | Meaning |
| --- | --- | --- |
| 3, 8, 19, 24 | **−8 in** | hub is left of tag |
| 9, 11, 25, 27 | **+8 in** | hub is right of tag |
| other hub tags (2, 4, 5, 10, 18, 20, 21, 26, …) | **0** | on-center face |

**Worked example:** tag 8 centered (`tx = 0`, `ty = 0`): hub 8 in left → `hubTx ≈ −7.3°`.

## 6. Pose → Limelight-style `tx` (sign-checked)

WPILib field: +X toward red, robot +X forward, **+Y left**. Limelight +tx is **right**.

```
dx, dy = hub − robot
forward =  dx * cos(θ) + dy * sin(θ)
left    = −dx * sin(θ) + dy * cos(θ)
txDeg   = atan2(−left, forward)     // = atan2(right, forward)
rangeIn = hypot(dx, dy) / 0.0254
```

Facing +X (`θ = 0`): hub at +Y (left) → **negative tx**; hub at −Y (right) → **positive tx**.

RB aim uses this for **look-ahead lead** and pose **distance fallback**. Heading fallback when the tag is gone is **last `tx` for 0.15 s**, then `tx = 0` (does not keep turning from pose). That is original feel, not a formula bug.

## 7. Moving shot (0.25 s look-ahead)

**Range** (inches), Limelight hub range minus distance closed toward the hub:

```
r_hat = (hub − robot) / |hub − robot|
closing_m = (fieldVx, fieldVy) · r_hat * 0.25
shotInches = cameraHubInches − closing_m / 0.0254
```

Moving **toward** the hub → shorter table distance. Standing still → unchanged. Bad/non-positive camera range → **75.125 in**.

**Lead `tx`:** `poseAimTx(futurePose) − poseAimTx(now)`, wrapped to (−180, 180]. Strafe left with hub ahead → **positive** lead tx (hub will be to the right). Drive straight at hub → lead **0**.
